# Security policy

## Supported versions

Security fixes are applied to the latest release and the default development branch.

## Reporting a vulnerability

Please use a private GitHub Security Advisory for this repository when the feature is available. If it is unavailable, contact the repository owner through the private contact method listed on the GitHub profile instead of opening a public issue.

Include:

- affected version or commit
- operating system and architecture
- concise reproduction steps
- impact and any suggested mitigation

Do not include passwords, tokens, private IP details, or unsanitized config.json/state.json files.

NetQuota is designed to keep usage and settings local. A report involving unexpected network access should include the exact command or build artifact that was used.
