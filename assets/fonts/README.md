# Bundled CJK fonts

NetQuota embeds these fonts so the portable desktop application can render its
正體中文 and 日本語 interface without relying on system-installed CJK fonts:

- `NotoSansCJKtc-Regular.otf` — Noto Sans CJK TC Regular
- `NotoSansCJKjp-Regular.otf` — Noto Sans CJK JP Regular

Both files are from the [Noto CJK project](https://github.com/notofonts/noto-cjk)
and are distributed under the SIL Open Font License 1.1 in `OFL.txt`.
